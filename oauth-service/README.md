# Smartsheet Controller OAuth service

This service is the server-side OAuth callback and short-lived token handoff for
the Smartsheet Controller Stream Deck plugin. The Smartsheet client secret stays
in Vercel environment variables and is never shipped in the plugin package.

## Required Vercel environment variables

- `SMARTSHEET_CLIENT_ID` and `SMARTSHEET_CLIENT_SECRET`: generated by Smartsheet Developer Tools.
- `OAUTH_STATE_SECRET`: a long random value used to sign OAuth state values.
- `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`: an Upstash Redis database connected to the Vercel project.

The Redis database holds only short-lived OAuth transactions. It is not the
long-term token store. After the plugin polls a completed transaction, the
transaction is deleted.

## Smartsheet redirect URL

After deploying this project, enter the exact production URL below in Smartsheet
Developer Tools:

`https://YOUR-VERCEL-DOMAIN/api/oauth/callback`

Do not use a preview deployment URL. The redirect URL must remain stable.

## Endpoints

- `POST /api/oauth/start` creates a signed authorization transaction.
- `GET /api/oauth/callback` receives the Smartsheet authorization code.
- `POST /api/oauth/poll` returns the completed token pair once and deletes the transaction.
- `POST /api/oauth/refresh` exchanges a refresh token without exposing the client secret.
