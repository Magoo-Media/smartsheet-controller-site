Everyday Smartsheet actions, one press away.

With user-authorized Smartsheet access, the plugin is designed to help users work with the sheets and rows they already have permission to use.

Open sheets and rows

Jump directly to frequently used Smartsheet work.

Update work

Add rows, update status, and assign work from Stream Deck.

Collaborate

Add comments and send update requests when follow-up is needed.

Stay ahead

Review sheet summaries and identify upcoming due items.

Create from templates

Start new sheets from available Smartsheet templates.

Built around your existing permissions.

Smartsheet Controller is not affiliated with, sponsored by, or endorsed by Smartsheet Inc. The plugin is intended to operate within the connected user’s existing Smartsheet permissions.

Availability, authorization, and supported actions may depend on the final public release configuration and the user’s Smartsheet account permissions.
